# 零点行动联机服务器

服务器提供 `GET /health` 健康检查与 `/game` WebSocket 游戏连接。默认监听 `PORT=3001`，生产环境监听所有网络接口。

```powershell
npm run server:start
```

房间、比分与重连令牌仅保存在内存中。服务器重启会结束当前房间，因此首版必须保持单实例运行。空比赛房间保留 60 秒，掉线席位保留 30 秒。收到 `SIGTERM` 或 `SIGINT` 后，服务器会停止计时器并关闭连接。

日志只包含服务生命周期事件和匿名标识，不应写入昵称或重连令牌。Render 免费实例休眠后首次连接可能需要等待冷启动；客户端会自动按 1、2、4、8 秒重试。
