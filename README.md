# 零点行动 · ZERO POINT

Windows 桌面枪战游戏，支持离线训练与 2–4 人互联网联机。请完整解压体验包后运行“零点行动.exe”。

## 0.3.0 武器与经济

每局所有真人和 NPC 都从 P-12 手枪、12 发弹匣和 0 金币开始。手枪备用弹药无限，但仍需要换弹。击杀 NPC 获得 150 金币，击杀真人获得 300 金币，上限 6000。

| 枪械 | 定位 | 躯干伤害 | 射速/分钟 | 弹匣 | 购枪价 | 弹药包 |
|---|---|---:|---:|---:|---:|---|
| P-12 | 半自动保底手枪 | 18 | 300 | 12 | 免费 | 无限备用 |
| V-9 | 自动冲锋枪 | 19 | 850 | 30 | 450 | 30 发 / 45 金币 |
| SG-8 | 泵动霰弹枪 | 12 × 9 | 75 | 6 | 600 | 6 发 / 60 金币 |
| AR-4 | 自动步枪 | 30 | 600 | 30 | 900 | 30 发 / 90 金币 |
| SR-7 | 栓动狙击枪 | 85 | 48 | 5 | 1500 | 5 发 / 100 金币 |

首次购枪附赠一满弹匣，备用为 0。买弹药只增加备用，不直接装入弹匣。可拥有多把枪，同时携带一把主武器与手枪；在商店装备已拥有主武器。每把枪分别保留弹药。

死亡保留金币、枪支和剩余弹药，不免费补弹。断线重连保留本局资产。下一局资产清零。NPC 遵守相同伤害、收益、购买及弹药规则，难度只影响行为。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | W / A / S / D |
| 射击 | 左键；冲锋枪与步枪可长按，其他枪点按 |
| 切换瞄准 | 右键点按；狙击枪显示瞄准镜 |
| 换弹 | R |
| 主武器 / 手枪 | 1 / 2 |
| 商店 | B；B 或 Esc 返回战场 |
| 奔跑 | 左右 Shift；移动中退出瞄准 |
| 跳跃 / 蹲伏 | Space / C 或 Ctrl |
| 设置 | Esc；单人暂停，联机仍继续 |

商店可在任意地点打开，打开后停止移动和射击，不暂停对局、不延长保护。购买需存活、静止，且最近 2 秒没有开火或受伤。阵亡可浏览，复活后购买。

## 对局

- 自由混战，先达到 15 次击杀获胜；5 分钟后比较击杀数。
- 阵亡 3 秒后复活，出生保护 3 秒。名字不透墙，蓝色护盾代表出生保护。
- 联机结算后房主可返回原房间，大家重新准备即可开下一局。
- 本局房间与经济保存在服务器内存；服务重启会结束房间。
- 公网地址：`wss://zero-point-game-server.onrender.com/game`。免费服务器休眠后的首次连接可能较慢。

## 开发与验证

Node.js 24。`npm run desktop:dev` 开发桌面客户端，`npm run server:start` 启动服务器。
`npm test` 运行回归测试，`npm run typecheck` 检查类型，`npm run client:build` 构建桌面页面。
分享包：`release/zero-point-0.3.0-win-x64.zip`。客户端与服务器都需更新至 0.3.0（协议 5）。
单人训练复用同一套战斗模拟，无需网络；本地不连接公网服务器。模型由代码生成，音效通过 Web Audio 合成。

验收建议：两人同房，检查手枪开局、NPC/真人金币差异、第一次购枪仅一弹匣、补弹扣费、换枪不刷弹、死亡保留、重连保留、下一局清零、B/Esc 鼠标恢复及狙击镜/霰弹枪反馈。
