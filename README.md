# 零点行动 · ZERO POINT

原创浏览器第一人称射击游戏，灵感来自经典竞技 FPS。电脑键盘、鼠标游玩。

## 开始

需要 Node.js 24 及以上。首次运行 `npm install`，然后 `npm run dev`，打开终端显示的本地地址。

选择难度并点击「开始行动」。点击后允许浏览器捕获鼠标；Esc 释放鼠标并暂停。浏览器不支持鼠标锁定时，按住右键拖动转向，或用方向键转向。

| 操作 | 按键 |
| --- | --- |
| 移动 | W / A / S / D |
| 射击 / 瞄准 | 鼠标左键 / 右键 |
| 换弹 | R |
| 步枪 / 手枪 | 1 / 2 |
| 冲刺 | 左 Shift（冲刺时无法射击） |
| 跳跃 | Space |
| 蹲伏 | C 或 Ctrl |
| 暂停、灵敏度、音效 | Esc |

## 规则

- 你对抗 4 名人机。你每击杀一名对手得 1 分，人机每击杀你得 1 分。
- 任意一方先达到 15 分获胜；5 分钟到时比较双方得分。
- 阵亡 3 秒后重生，玩家有 2.5 秒出生保护，人机有 1 秒保护。
- 枪械有弹匣与备用弹药；击杀补充备用弹药，重生补满。
- 人机巡逻、视觉感知、追击最后看到的位置，并沿网格绕开障碍。
- 当前为一张原创低多边形地图、单人击杀竞赛；不含联网多人或拆弹模式。

## 验证

`npm test` 验证碰撞、导航、射线命中、爆头、遮挡、出生保护、换枪和重开。
`npm run typecheck` 检查类型，`npm run build` 生成生产包。

3D 模型与材质由代码生成；音效通过 Web Audio 合成。浏览器需支持 WebGL 2。源码包含完整游戏逻辑，所有游戏计算在客户端运行。
