# 零点行动 · ZERO POINT

原创第一人称射击游戏，灵感来自经典竞技 FPS。支持离线人机训练，以及通过互联网房间码进行 2–4 人联机。电脑键盘、鼠标游玩。

联机服务器使用独立 WebSocket 服务，当前公共服务器为 `wss://zero-point-game-server.onrender.com/game`，部署说明见 `server/README.md`。

## 开始

开发源码需要 Node.js 24 及以上。安装组件后执行 `npm run client:dev`；联机服务器另开终端执行 `npm run server:start`。

正式分享包位于 `release/zero-point-0.2.5-win-x64.zip`。把这个压缩包发给朋友；对方完整解压后双击“零点行动.exe”即可，不需要 Node.js 或管理员权限。主界面选择「互联网联机」，一人创建房间并把六位房间码发给其他人，全部准备后由房主开始对局。支持 2–4 名玩家，并可加入人机补位。

公共服务器使用 Render 免费实例，长时间无人使用后首次连接可能需要等待约一分钟。服务器重启时，已经创建的房间会被清空，重新创建即可。

选择难度并点击「开始行动」。点击后允许浏览器捕获鼠标；Esc 释放鼠标并暂停。Codex 等嵌入式预览可能禁止鼠标锁定，请用独立 Chrome / Edge 打开在线地址。锁定失败时，直接在游戏画面内移动鼠标仍可转向，也可点击「再次锁定鼠标」。

| 操作 | 按键 |
| --- | --- |
| 移动 | W / A / S / D |
| 射击 / 瞄准 | 鼠标左键 / 右键 |
| 换弹 | R |
| 步枪 / 手枪 | 1 / 2 |
| 冲刺 | 左 Shift（冲刺时无法射击） |
| 跳跃 | Space |
| 蹲伏 | C 或 Ctrl |
| 暂停、灵敏度、音效 | Esc |

## 规则

- 你对抗 4 名人机。你每击杀一名对手得 1 分，人机每击杀你得 1 分。
- 任意一方先达到 15 分获胜；5 分钟到时比较双方得分。
- 阵亡 3 秒后重生，玩家有 2.5 秒出生保护，人机有 1 秒保护。
- 枪械有弹匣与备用弹药；击杀补充备用弹药，重生补满。
- 人机巡逻、视觉感知、追击最后看到的位置，并沿网格绕开障碍。
- 当前为一张原创低多边形地图和击杀竞赛；不含拆弹模式。

## 验证

`npm test` 验证碰撞、导航、射线命中、爆头、遮挡、出生保护、换枪和重开。
`npm run typecheck` 检查类型，`npm run build` 生成生产包。

3D 模型与材质由代码生成；音效通过 Web Audio 合成。电脑需支持 WebGL 2。离线模式在本机运行；互联网联机的房间和对局状态由服务器统一处理。

## 0.2.5 联机修复验收

客户端与服务器均需更新至 0.2.5（协议 4），旧包不能连接新版服务器。

- 左右 Shift 均可奔跑；移动中按 Shift 退出瞄准，松开恢复走路。蹲伏时不奔跑。
- Esc 设置含灵敏度滑条、加减、数值和重置，单机联机共享并保存。
- 结算后房主返回原房间，所有人重新准备即可下一局，无需重输房间码。
- 训练菜单、暂停、结算均有返回模式选择。
- 玩家/NPC 有身份色和头顶名称；名称不透墙。受击闪色，出生保护有蓝色护盾。
- 网络异常时显示恢复状态。Esc 中可查看 RTT、快照间隔、积压输入、本地帧耗时、服务器步进耗时，方便反馈卡顿原因。

建议两人实测：同房连玩三局；分别测试左右 Shift、瞄准后奔跑和蹲伏；灵敏度调为 0.3/2.5 对比并重启检查保存；射击刚复活与保护结束的目标；短暂断网 1–3 秒后观察恢复；检查墙后不显示名字。
