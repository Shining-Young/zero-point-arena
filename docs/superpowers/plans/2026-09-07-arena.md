# Arena Implementation Plan

**Goal:** Deliver a playable original FPS with AI opponents.
**Architecture:** Pure combat/navigation rules, an imperative Three.js engine, and a React game shell.
**Tech Stack:** Vinext, React, TypeScript, Three.js, Node test runner.
**Spec:** ../specs/2026-09-07-arena-design.md

## Global constraints
- Chinese interface; desktop keyboard and mouse.
- Offline gameplay logic; local bundled assets; no external asset URLs.
- 4 bots, 15-kill target, 300-second matches, 3 difficulty settings.
